# Deploy this TP53 README on GitHub

This package is prepared as a GitHub repository README. GitHub automatically renders `README.md` on the repository home page.

## 1. Create a repository

1. Sign in at https://github.com/.
2. Select **+** → **New repository**.
3. Enter a repository name, such as `TP53`.
4. Choose **Public** if you want the page to be publicly viewable.
5. Select **Add a README file** only if you are creating the repository without uploading this package's README. If you upload this package, avoid creating a conflicting second README.
6. Create the repository.

## 2. Upload the files

1. Open the new repository.
2. Choose **Add file** → **Upload files**.
3. Upload `README.md` and the `images` folder (including `images/README.md`).
4. You may also upload `DEPLOYMENT.md` if you want to keep these instructions in the repository.
5. Select **Commit changes**.

## 3. Add your ChimeraX screenshot

1. In ChimeraX, use **Snapshot** to save your final structure image as `tp53_3kmd.png`.
2. Upload that image into the repository's `images` folder.
3. Edit `README.md` and find the commented image line:
   `<!-- ![TP53–DNA structure (3KMD) visualized in ChimeraX](images/tp53_3kmd.png) -->`
4. Remove `<!--` at the beginning and `-->` at the end, then commit the change.

The screenshot is not included in this starter package because a final ChimeraX visualization was not provided with the Word document.

## 4. View and share

Open the repository home page. GitHub renders the README automatically. Share the repository URL, for example:

`https://github.com/YOUR-USERNAME/TP53`

Replace `YOUR-USERNAME` with your GitHub username.

- The README content is based on the supplied `TP53_English.docx`.
- The source document gives `ARG 273` for Question 3 and asks the student to identify a cancer-associated mutation for Question 5; it does not provide a completed answer to Question 5.
- The `.cxs` session file is created and saved from ChimeraX; it is not generated by this README package.
